# 이찬우 Backend Developer Portfolio

GitHub Pages에 배포한 범용 개발자 포트폴리오 사이트입니다.

## 구성

- `index.html`: 포트폴리오 메인 페이지
- `styles.css`: 반응형 스타일
- `assets/`: 프로젝트 캡처 이미지와 프로필 이미지
- `.nojekyll`: GitHub Pages 정적 파일 처리를 위한 설정

## 소개 프로젝트

- AI Agent 기반 B2B 자동 발주 SaaS MVP (`#project`)
- 공공시설 예약 지도·접수 오픈 알림 앱 운동자리, Google Play 출시 (`#undongjari`, https://play.google.com/store/apps/details?id=com.chanwoo.undongjari)
- 한국어 특화 음성 입력기 말로(Mallo), 공개 베타 출시 (`#mallo`, https://www.project-mallo.com/)

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다. 예: `lee-chanwoo-portfolio`
2. 이 폴더 안의 파일을 저장소 루트에 업로드합니다.
3. 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, 폴더는 `/root`로 선택한 뒤 저장합니다.
5. 배포가 끝나면 `https://계정명.github.io/저장소명/` 주소로 접속할 수 있습니다.

개인 연락처 보호를 위해 공개 웹 페이지에는 이메일만 노출했습니다.
